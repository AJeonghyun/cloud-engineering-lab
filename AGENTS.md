# Project Instructions

## Project Goal

This repository is a hands-on learning project for exploring
Cloud, Infrastructure, and DevOps engineering.

The goal is not to generate a complete system as quickly as possible.
The goal is to understand, implement, troubleshoot, and document each component.

## AI Usage Rules

- Do not generate complete infrastructure configurations unless explicitly requested.
- Prefer hints and diagnostic steps over direct fixes.
- Ask the learner to inspect logs and system state before suggesting solutions.
- Explain why each command or configuration is used.
- Do not automatically implement future phases.
- Review learner-written configuration rather than replacing it.

## Documentation Rules

Important work should be recorded in:

- `docs/worklogs/`
- `docs/incidents/`
- `docs/architecture/`

Incident reports should include:

- Symptom
- Investigation
- Root Cause
- Resolution
- Verification
- Prevention / Improvement
